# 固定 ISP 出口池

管理页「代理」中的「固定 ISP 出口池」用于把 Codex 账号显式加入一个固定的 ISP 出口池。功能默认关闭，账号绑定会保留健康资源；系统不会自动重平衡，也不会自动远程停止资源。请通过「同步」或「启动一项」手动补充资源，并遵守提供商的容量和补充间隔限制。

池设置使用稳定默认值：冷却 600 秒、最多尝试 3 次、429 与 5xx 轮换均关闭。关闭功能不会解除已加入账号；请先逐个「解除」绑定，才能恢复账号之前保存的路由。手动轮换只接受当前 generation，并要求同池、健康且出口 IP 不重复的备用资源。

提供商保存只提交非空 API key。快照从不返回密钥，已配置的提供商显示「已配置密钥」，编辑时留空会保留现有密钥；保存成功后输入框会被清空。首次保存提供商必须填写密钥。协议、认证格式（`1`、`2`、`3`）、端口范围、容量和补充间隔均显式填写，不根据端口猜测 TLS。

静态导入只会创建待验证资源。使用「测试」完成真实代理出口探测；目标自身失败等不确定结果会保留旧状态，出口漂移会隔离。导入资源不会尝试远程停止；只有 `owned` 且未绑定、已耗尽的资源可执行「停止」。未知启动任务必须先同步确认，管理页不会盲目重复启动。

界面每 10 秒刷新快照，但存在未保存草稿时不会覆盖池和提供商编辑内容；写入错误会留在面板直到下一次成功操作。浏览器测试使用 API 拦截，不需要真实提供商凭据。

提供商实际 API 兼容性取决于服务商返回的协议和认证格式。管理页只验证管理 API 的响应，不把一次成功的管理请求当作真实出口可用性的保证；请在资源表中执行测试后再绑定账号。

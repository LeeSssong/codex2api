# State 模型范围修复

严格 State 条件现在直接使用「采集设置」中保存的模型勾选。只勾选 Sol 和 Astra 时，这两个模型必须有匹配的有效 State；Terra、Luna、codex-auto-review 等未勾选模型不受自动 State 门槛拦截。无需新增配置或迁移数据库。

选号和发送前校验使用同一范围。取消勾选并保存后立即解除该模型的自动 State 门槛；重新勾选恢复严格校验。关闭自动复用时，已勾选模型仍按严格规则拒绝，未勾选模型继续正常路由。账号授权、真实冷却、模型权限及普通并发检查保留。

本次同时包含两项兼容修复：

- 管理端单个 / 批量测试遇到本地 State 策略拒绝时，报告原因但不把账号写成故障，也不覆盖已有冷却。不会自动恢复历史故障账号。
- 将现有生产补丁的只读 `/api/admin/state-pool/supply-signal` 接口纳入正式镜像，保持后台补号服务兼容。

验证覆盖所选模型严格拒绝、未选模型正常调度和续链、配置切换、过期 State、账户范围、管理测试错误分类及补号接口。

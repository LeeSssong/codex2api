# 10 月 16 日更新内容与使用入口

来源：服务器已核实运行的整合提交 `9d18793064af63e9533ab753a4b738e8c5d07a03`，合并官方 `8cd964bb` 与 hloolx `2caf579b`。以下是该次更新，区别于此前的 v3.0.6 更新。智能运维的移除另行验收。

| 来源 | 更新 | 入口与用法 |
| --- | --- | --- |
| 官方 | 账号降智检测：题目、检测结果历史和自动处置 | `/admin/intelligence-check`；配置检测题目和策略，账号页也可发起检测与查看结果 |
| hloolx | 按账号、模型自动检查质量；错误答案暂停该模型，复测通过恢复 | `/admin/quality-test?view=monitor` → 自动检测；选择模型并开启，默认关闭，检测消耗额度 |
| hloolx | 专用宿主 IPv6 出口、账号地址绑定及有限故障轮换 | `/admin/proxies` → 专用宿主 IPv6 出口；先确保容器能绑定可用公网 IPv6，再配置地址池并开启；不能仅凭主机有 IPv6 就认定可用 |
| 官方 | API Key 实时请求并发显示 | `/admin/api-keys`；活跃 Key 旁显示当前并发/上限，每 5 秒刷新，数值为当前实例 |
| 官方 | Antigravity 账号批量操作、配额详情、导入导出增强 | `/admin/accounts/antigravity`；选中账号执行批量操作，点击配额查看详细窗口 |
| 官方 | WebSocket 续链恢复、独立闲置连接保留预算 | `/admin/settings` → Codex WebSocket 相关设置；客户端继续使用原地址，连接丢失时在条件允许下恢复完整上下文 |
| 官方 | Responses 字段、工具历史、HTTP/WS 多流续链兼容性修复 | 现有 `/v1/responses` 和客户端接入路径自动生效，无需换地址 |
| 官方 | 使用统计按小时汇总，长时间范围查询优化 | `/admin/usage` 与公开 Key 用量页；查询长时间范围，结果口径保持一致 |
| 官方 | Antigravity Claude 工具调用、模型路由与结构化输出修复 | 原有 Messages、Chat、Responses 接口自动生效；仍受上游模型能力限制 |
| 官方 | Gemini 4 Argon 模型目录及不可用模型占位状态 | Antigravity 账号、模型选择与模型管理页面；以账号实际访问权限为准 |

此次整合保留原有 State、BPS、提示词过滤、图片能力及账号身份设置。截图中的“智能运维”七个模块和插件管理是本地 Sub2API 移植定制，不属于上表的官方降智检测或 hloolx 自动模型质量检查。移除这组定制功能不会同时移除这两个新版检测入口。

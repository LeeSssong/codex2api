# 智能运维退役与凭证运营

原 Sub2API 移植的智能运维模块、插件管理和独立凭证执行器已从应用移除。专属配置、任务、历史和加密登录资料通过升级迁移删除。普通账号、凭据、API Key、并发设置和新版独立检测功能保留。

新版入口参见 [更新与使用指南](releases/2026-10-17-update-usage-guide.md)。旧实施及发布记录仅用于历史追溯，不是当前操作指南。

2026-10-18 的独立凭证运营迁移分支新增首次 2FA 登录、重登、巡检和恢复功能。它使用新的专用表、原生页面及应用自有 Worker；使用说明见 [凭证运营与首次 2FA 登录](credential-operations.md)，实现验收与生产部署状态分开记录。

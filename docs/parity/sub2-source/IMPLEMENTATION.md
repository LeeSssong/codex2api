## 边界与实际含义

- 账号费用同输入/同统计规则/同目录可对照来源；两边请求集合和配置值不自动同步。
- 用户扣费仍为Codex2API原生实际收费，未迁移Sub2整套用户/渠道售价或8位用户扣费规则。user_usd明确表示本系统实际用户费用，不能称两边所有收费系统完全相同。
- 上游目录可配置，内置表固定来源版本；不会自动读取Sub2线上目录和规则。源请求动态分组需配置对应source_group_id；不是跨系统自动迁移。
- 旧记录缺少原始证据和当时价格，保留原记账值并标legacy/mixed，不能回溯声称与源精确一致；无自动历史回灌。
- 精简费用仅在数据库事务提交后持久。当前沿用原生异步缓冲，进程崩溃/数据库故障缓冲超限可能丢尚未提交事件；不声称全链路零丢失。新费用表不随普通诊断日志清理；长期保留策略需在发布前运维容量评估，未自行删除财务历史。
- 原共享工作区未覆盖；子任务各自worktree、明确提交整合，生产版本和远端main均未改变。
